# Calculadora em Java (Swing / WindowBuilder)

Projeto desenvolvido para a disciplina de **Programação Orientada a Objetos (POO)** utilizando Java Swing e o plugin WindowBuilder no Eclipse.
## Funcionalidades Implementadas

A aplicação realiza operações matemáticas básicas e avançadas por meio de métodos dedicados:

* **Adição (`adicao`):** Soma dois valores numéricos.
* **Subtração (`subtracao`):** Calcula a diferença entre dois números.
* **Multiplicação (`multiplicacao`):** Realiza o produto entre dois valores.
* **Divisão (`divisao`):** Divide dois números com tratamento para divisão por zero (`"Erro"`).
* **Potência (`potencia`):** Eleva uma base a um expoente utilizando `Math.pow()`.
